## 0.1.0 - 2026-10-26

### Added
- `raik` orchestrator: stage routing, five workflow gates, `status`, `next` and `decide-for-me`.
- Define skills: `raik-init`, `raik-product`, `raik-domain`, `raik-architecture`, `raik-design`, `raik-ui`, `raik-roadmap`.
- Deliver skills: `raik-decide`, `raik-change`, `raik-build`, `raik-debug`, `raik-verify`, `raik-review`, `raik-ship`.
- Operate and continuity: `raik-ops`, `raik-memory`.
- Profiles: `python-fastapi-modular` (with tested import-linter contracts) and `react-vite-ts`; architecture concerns checklist.
- Scripts: `archive_links.py` (repair links after archiving a change) and `contrast.py` (WCAG contrast), with tests.
- Docs: architecture, configuration, standards index, external skills, roadmap, ADRs 0001-0003.
- Repo validation, CI and release workflows, Claude Code plugin manifests.
